分析相關樣本

受害者觸發惡意程式的方式 (載入流程/誘發方式/可能有的加解密/等等)

解壓後看到一個 .jse 檔案，可能透過釣魚郵件的方式讓使用者解壓縮點擊執行，Windows 會把它當成 Javascript 執行。

用編輯器看會發現是明文，但有些許混淆:

  • 前幾個變數是大量的 base64，猜測是在做一個 decode malware 本體的動作

稍微整理一下就變得很好懂:

  • 相關所有檔案都會放在 C:\ProgramData\ 下
  • base64_2 decode 會存到 System Safety Manager JD.pdf
    • 並執行這個 pdf
  • base64_3 decode 則會存到 3hsOE4s.JaBu
  • 之後執行 powershell.exe -windowstyle hidden certutil -decode C:\ProgramData\3hsOE4s.JaBu C:\ProgramData\a2rqpns.u53Z
    • 把 3hsOE4s.JaBu 再 decode 為 a2rqpns.u53Z
  • 最後跑 powershell.exe -windowstyle hidden cmd /c cmd /c regsvr32.exe /s C:\ProgramData\a2rqpns.u53Z
    • a2rqpns.u53Z 很大機率是 DLL，此為惡意程式主要邏輯

decode 後的 System Safety Manager JD.pdf 看起來就真的只是個 pdf:

  • 使用的工具是 PDFiD，會檢查 pdf 是否包含 malicious feature

Hex editor 打開 pdf 檢查:

  • magic number 為 PDF

惡意程式族群

  • Kimsuky

將 a2rqpns.u53Z 的 md5 537806c02659a12c5b21efa51b2322c1 拿去 VirusTotal 搜尋就會找到:

  • 被多家廠商標示為 Kimsuky

PDF 有韓語相關訊息:

樣本編譯時間 + 推測攻擊時間

根據 PE Header 中的 TimeDateStamp 欄位，編譯時間為 2024-05-13 02:01:12 UTC。

根據 VirusTotal 的紀錄 First Seen In The Wild 2024-05-17 11:50:48 UTC，可以推測第一次攻擊介於這兩個時間之間。

TimeDateStamp 是可以更改的，也有可能在更早一前就出現並攻擊了。

Decoy 檔案

System Safety Manager JD.pdf 前面有分析過這看起來就只是個 pdf，用途應該是執行 .jse 後讓使用者誤以為只是打開一個 pdf。

此 pdf 看起來為一份 General Dynamics Land Systems 的職缺說明文件。

C2

相關 domain: http://download.uberlingen.com/index.php

C2 主要邏輯在 sub_1800049C0。

首先嘗試看 C2 建立連線，失敗的話 sleep 五分鐘，再試一次，成功的話則進入收指令的環節:

C2 指令如下:

  • d: 使用 cmd.exe 執行命令並回傳結果
  • e: 從 C2 下載檔案
  • f: 上傳檔案到 C2
  • g: CreateProcessW
  • i: 刪除檔案
  • j: 截圖上傳到 C2
  • k: 像 C2 傳當前 config
  • l: 更新 config
  • m: 連線指定的 host, port
  • n: 睡一個指定時間
  • o: 把來源檔的 timestamp 複製到目標檔
  • p: self deletion
  • r: 類似於 d

self deletion 流程:

  1. GetModuleFileNameW 取得當前路徑
  2. 建立 %TEMP%\msbuild.bat 並執行
  3. 把 persistence 寫的 registry 清掉
  4. 回報 C2 OK
  5. Terminate Process

Persistence

在 address 0x180003530 這個 function 是做持久化相關的功能。

首先這個 function 會 call sub_180002440 檢查 process 是否是管理員權限，是的話直接 CreateProcessW 執行:
mshta.exe "javascript:var o=new ActiveXObject('WScript.Shell');o.Run('C:\\Path\\to\\malware.exe',0);"

不是的話執行以下:

  1. RegOpenKeyExW 打開 HKCU\software\microsoft\windows\currentversion\run
  2. RegQueryValueExW 檢查 CacheDB 是否為空
  3. 空的話用 RegSetValueExW 把 mshta.exe "javascript:var o=new ActiveXObject('WScript.Shell');o.Run('C:\\Path\\to\\malware.exe',0);" 寫進去
  4. RegCloseKey

分析受害/攻擊者身分

根據 System Safety Manager JD.pdf 可以分析出多項資訊。

受害國家

PDF 直接寫：

  • Location: Berlin, Germany

代表攻擊者想讓受害者認為是一份德國職缺，因此受害國家應是德國、和此公司有相關業務的國家、歐洲國家都有機會。

攻擊族群

正在找 System Safety Manager 相關工作的人，且具有 CS 或相關科系學歷。

Config offset + decoding method

sub_180003F30 這支 function 有相關的功能。

  1. CreateFileW 打開自身的 ADS :info
  2. :info 不存在就執行 RC4 解密 size 為 4652 的 byte_18003CA50，並寫進 :info
  3. 如果 :info 存在就直接讀取裡面的內容
  4. 將解密的結果存到 C2 的 struct_a1->pBuf4652
    • 結構如下:
  5. 在 4648 的位置寫入 4byte (rand() * rand() / 2)

這一段為第一步:

這一段為 RC4 + rand() * rand() / 2 + 寫入

  • 第一個 while 做 Key Scheduling，第二個 while 為 RC4 的 PRGA

byte_18003CA50 解出來的內容只有兩個寬字串:

  • http://download.uberlingen.com/index.php
  • C:\Windows\System32\cmd.exe
